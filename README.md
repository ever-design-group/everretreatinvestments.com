 Ever Retreat Investments Vill

A powerful, high-speed website showcasing the investment opportunities of building eco-houses in Rwanda and across Africa.

---About

Ever Retreat Investments Vill is a real-world development website that showcases the investment opportunities of building eco-houses in Rwanda and across Africa.

Powered by Ever Retreat — a company that has already started this development and has a villa prototype built in Rubavu — this platform brings the vision of sustainable, luxury eco-living to life.

The website is designed to attract investors, showcase villa developments, and highlight the massive potential of eco-house investments across the African continent.

 Key Highlights

- Eco-House Investment Opportunities — Showcasing sustainable villa developments in Rwanda and beyond

 Tech Stack

Built with modern web technologies for maximum performance:

- Next.js — React framework for production
- TypeScript — Type-safe development
- Tailwind CSS — Utility-first styling
- Framer Motion — Smooth animations
- Optimized for Speed — Fast load times, responsive, and scalable

---


Clone the repository and install dependencies:

```
git clone https://github.com/JCodesMore/ai-website-cloner-template.git
cd ai-website-cloner-template
npm install
npm run dev
```

Open http://localhost:3000 in your browser to view the site.

---

 Build for Production

```
npm run build
npm run start
```
